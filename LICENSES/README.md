# Licensing

This repository uses a permissive open-access licensing structure:

- Source code is released under the MIT License. See `../LICENSE`.
- Non-code research artifacts are released under CC BY 4.0 unless otherwise noted. See `CC-BY-4.0.md`.

This split keeps the software easy to reuse while making documentation,
reference metadata, and reproducibility artifacts openly citable and
redistributable with attribution.

Third-party datasets, external publications, and package dependencies are not
relicensed here and remain under their original licenses.
